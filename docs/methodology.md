# Research methodology (summary)

The full approved methodology is in docs/foundation-proposal.md (exported from the planning doc).
CLAUDE.md contains the rules in short form. Key points:

- Source hierarchy: archaeological and material evidence; contemporary primary sources; later primary
  sources; academic secondary works; reputable reference and museum works; general sources (only to
  find better ones, never cited alone for a graded claim).
- For each source record: author's position, distance from the events, purpose and audience.
- Verification statuses: draft → sourced → verified → reviewed.
